# AI Chatbot

A web-based AI chatbot built with Python, Streamlit, and Ollama.

## Features
- Interactive chat interface
- Chat history
- Dark and light themes
- File upload support
- Coding assistance

## Tech Stack
- Python
- Streamlit
- Ollama / Llama 3.2

## Run Locally
1. Install the dependencies: `pip install -r requirements.txt`
2. Install Ollama and pull the required model.
3. Start Ollama.
4. Run the app: `streamlit run app.py`
